# Trabalho no Portfolio RyderMais

Leia o README e os documentos da entrega antes de editar. Atualize requisitos, contratos e critérios de aceite no mesmo PR que os altera. Siga a ordem e a propriedade de arquivos de [implementação](docs/05-implementacao.md). Registre evidências de teste e pendências no PR.

Trabalhe dentro deste repositório. Use Bun e `bun.lock` na web, Cargo e `Cargo.lock` na API. Use fixtures sintéticas e serviços locais para desenvolvimento. Mantenha tokens, exports do LinkedIn, credenciais e dados pessoais fora do Git. Use o projeto Railway identificado no runbook e trate alterações de produção como etapas explícitas de release.
